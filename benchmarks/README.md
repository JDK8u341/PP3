# 冷启动与热执行测量

在仓库根目录运行：

```text
python benchmarks/run.py --repeat 7 --output benchmarks/results-local.json
```

无需网络或第三方依赖。默认使用本目录固定的纯 DSL 样本；`--challenges 路径` 可改用其他题库检出，比较前须明确版本。样本来源与完整性见 [fixtures](fixtures/README.md)。

## 测量方式

- 基线使用独立 `ReferenceRuntime`，其 run 保留优化前实现，不用自动执行器再包一层作为基线。
- 对比扁平字节码候选、默认 auto 和诊断 specialized。
- 每轮 cold 清空代码缓存，计入 run 内检查和编译；字节码候选另外把转换成本加入 cold。
- hot 在同一 IR 上执行 `clear()` 后重跑，保留代码缓存，但清除内存和字符缓冲。
- build、Runtime 初始化、编译秒数分别记录；表格中的运行秒数不含 build 或 Runtime 初始化。
- 每条路线先比较输出、完整内存及插入顺序、view、异常和剩余缓冲。任何差异立即终止测量。
- 每项取 7 次中位数。微秒级短任务的 hot 另外按 2000 次批量计时求每次均值，再取中位数，减少计时器噪声。

扁平字节码是针对普通标准 IR 的研究候选，没有生产后端的全部动态接口保护，仅用于了解集中分派的收益，不属于兼容公共 API。

## 本地结果

[原始 JSON](results-windows-py312.json) 记录 2026-11-07 的 Windows 11、CPython **3.12.14** 本地测量。单位毫秒；auto 的 cold 已包含编译成本。

| 程序 | 原版 cold | auto cold | 原版 hot | auto hot | hot 加速比 | auto 编译成本 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| P003 十进制编解码 | 74.82 | 18.17 | 73.22 | 12.18 | 6.01x | 4.93 |
| P004 有符号乘法 | 68.95 | 20.73 | 69.35 | 8.74 | 7.94x | 10.61 |
| P005 GCD | 129.73 | 35.26 | 132.81 | 14.84 | 8.95x | 14.64 |
| P006 ROT13 | 458.36 | 152.03 | 455.52 | 139.13 | 3.27x | 8.66 |
| P007 链表归并 | 509.36 | 118.98 | 550.23 | 91.69 | 6.00x | 22.02 |
| P008 wc | 257.46 | 155.79 | 260.39 | 141.03 | 1.85x | 16.72 |

这些题目均关闭直接寻址。输入规模固定：P006 为 128 字符、P007 为 128 个逆序码点、P008 为 200 字符；其他输入见 `run.py`。它们不是任意程序的普遍加速承诺。

微基准中，200000 次递减的 hot 为 8.97x，固定深度寻址为 7.96x，大整数操作为 6.72x。扁平字节码候选在六题中约为 1.39..1.55x，因此没有选为默认后端。

## 短任务的代价

auto 并不保证对所有程序更快。短直线、3 次循环、9 次循环都没有编译，但入口与热点检查仍有成本；本机批量 hot 均值分别约为：

| 微基准 | 原版 | auto |
| --- | ---: | ---: |
| 短直线 | 1.06 微秒 | 1.60 微秒 |
| 3 次循环 | 0.93 微秒 | 2.14 微秒 |
| 9 次循环 | 2.20 微秒 | 4.66 微秒 |

诊断 specialized 还会对短循环立即检查/编译，可能明显更慢，故默认使用 auto。未知循环无法总能提前知道何时退出；8 次热点阈值只是已测工作负载的折中，不能视为最优保证。对于以极短 run 为主的宿主调用，参考路径可作为测量对照。

## 解释结果的限制

表内是原版 Python 大整数、内存和 I/O 语义下的墙钟结果，不是 PP3 指令减少的比例。输出捕获到 StringIO，真实终端耗时可能成为主要瓶颈；没有删除每字符 flush。CPU 频率、系统负载、Python 版本和数据分布都会改变比值。

此次未实现或测量 pybind11、PyO3 或机器码 JIT，不将它们的潜在效果写成实测结论。路线依据和兼容性条件见[执行器设计](../docs/executor.md)。
